# Airbnb

강의 OT에서 [[비즈니스 모델링]]의 사례로 쓰인 기업. "Doing right things"(다른 기업과 다른 것을 한다)의 예로 제시되며, 대비 사례는 Hilton("Doing things right").

## 비즈니스 모델 캔버스 (슬라이드 작성 예시)
| 블록 | 내용 |
|---|---|
| 핵심 파트너 | 투자자, 여행객, 호스트, 보험 회사, 결제 회사 |
| 핵심 활동 | 플랫폼 유지, 고객 지원, 사용자 연구 |
| 핵심 자원 | 호스트·고객 커뮤니티, 플랫폼, 개발자 & 스태프 |
| 핵심 가치 | 호스트는 숙소를 제공하며 수익 창출 / 고객은 합리적인 가격으로 특별한 숙소 이용 |
| 고객 관계 | 자동화된 서비스, 고객 지원 |
| 채널 | 광고, 소셜 미디어, 소개, 제휴 |
| 목표 고객 | 숙소 이용 고객(게스트), 숙소 제공 고객(호스트) |
| 비용 구조 | 마케팅·고객 지원 비용, 직원 인건비, 플랫폼 유지비 |
| 매출 구조 | 호스트 비용, 고객 비용 |

> 위 표는 강의 슬라이드의 예시이며 Airbnb의 실제 공시 내용과 같은지는 [확인 필요].
