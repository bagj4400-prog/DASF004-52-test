# 창업 단계별 학습 로드맵 (종합)

세 자료(OT, 2주차, 3주차(Ch.3))를 연결해 본 큰 그림.

```
[동기·마인드셋]            [아이디어 검증]                       [모델링]
기업가정신 ─────────────▶ 기회 인식 ─▶ 타당성 분석 ─────────▶ 비즈니스 모델
(2주차)                    (제2장)       (제3장, 4주차)           (제4장, OT 예시)
```

1. **왜·누가** — [[기업가정신]], [[성공한 기업가의 특징]], [[기업가에 대한 오해]]가 출발점. 창업 동기와 필요한 자질을 정리한다.
2. **어떤 유형으로** — [[스타트업 유형]]에서 생계형/라이프스타일/창업기업 중 무엇을 목표로 하는지 정한다.
3. **될 만한가** — [[타당성 분석]]의 4개 영역([[제품 서비스 타당성]] → [[산업 목표시장 타당성]] → [[조직 타당성]] → [[재무 타당성]])을 모두 통과해야 사업계획서로 진행. 하나라도 탈락하면 포기 또는 수정.
4. **어떻게 돈 벌 것인가** — [[비즈니스 모델링]]: 부가가치 사다리와 캔버스(예: [[Airbnb]])로 설계.
5. **전체 지도** — [[창업 프로세스]]의 4단계, 일정은 [[혁신과 사회적책임 (강의)]].

## 공통 맥락 (연결 관찰)
- 타당성 분석은 "초기에, 자원 투입 전에" 아이디어를 거르는 장치이며, [[기업가에 대한 오해]]의 '도박꾼 아님(적정 위험 감수)'과 같은 취지를 가진다. *(이 연결은 위키 작성 시점의 해석이며 강의 자료가 직접 명시한 것은 아님 — [확인 필요])*
- 조직 타당성의 "창업자 열정·시장 이해"는 [[성공한 기업가의 특징]]의 '열정'·'제품/고객 중심'과 대응된다. *(동일하게 해석 — [확인 필요])*
