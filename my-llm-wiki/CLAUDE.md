# Wiki 운영 규칙

## 1. 이 위키의 목적
이곳은 AI/ML 트렌드와 개발 지식을 모아두는 개인 연구 지식베이스입니다.

## 2. 절대 규칙
- `raw/` 폴더에 있는 파일은 절대 수정하거나 삭제하지 마세요. (읽기 전용)
- 확실하지 않은 내용은 절대 단정 지어 말하지 말고 `[확인 필요]`라고 표시하세요.
- 모든 위키 페이지 하단에는 반드시 `raw/` 폴더의 출처를 명시하세요.

## 3. Ingest (흡수) 워크플로우
내가 "새 자료를 Ingest 해줘"라고 명령하면 다음을 수행하세요:
1. `raw/` 폴더의 새 자료를 읽고 핵심을 파악합니다.
2. `wiki/` 폴더에 기존 관련 페이지가 있다면 내용을 덧붙여 업데이트합니다. (새 페이지 생성보다 우선)
3. 서로 관련된 페이지끼리는 `[[페이지 이름]]` 문법으로 백링크를 연결하세요.
4. 작업이 끝나면 `index.md` 카탈로그와 `log.md` 작업 기록을 갱신하세요.
